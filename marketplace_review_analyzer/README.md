# Анализ рейтингов и негативных отзывов WB / Ozon

Streamlit-приложение автоматически читает актуальный Excel-файл с товарами, получает рейтинги и отзывы Wildberries/Ozon, фильтрует негативные отзывы, классифицирует проблематики и формирует отчёты TXT, DOCX и XLSX.

## 1. Установка

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`, если используете реальные API:

```env
WB_API_TOKEN=...
OZON_CLIENT_ID=...
OZON_API_KEY=...
```

## 2. Запуск

```bash
streamlit run app.py
```

Откройте локальный адрес, который покажет Streamlit.

## 3. Как загрузить Excel

В интерфейсе нажмите блок загрузки и выберите `.xlsx`. Программа не использует захардкоженный список товаров: при каждом запуске она заново читает загруженный файл.

Поддерживаемые заголовки: `Продукт`, `Товар`, `Наименование`, `Ссылка`, `URL`, `Артикул`, `SKU`, `Категория`, `Вариант`, `Оттенок`, `Тон`. Блоки или листы могут называться `WB`, `Wildberries`, `ВБ`, `Ozon`, `Озон`.

## 4. Как выбрать период

Выберите дату начала и дату окончания. В отчёт попадут только отзывы, дата которых входит в выбранный интервал включительно.

## 5. Как получить отчёт

Нажмите **Сформировать отчёт**. Приложение покажет прогресс, карточки товаров, текстовый отчёт и кнопки скачивания:

- TXT;
- DOCX;
- XLSX.

## 6. Как добавить новые товары в Excel

Добавьте строки в соответствующий блок WB/Ozon или на соответствующий лист. При следующей загрузке файла программа прочитает новые строки автоматически.

## 7. Как удалить товары из Excel

Удалите строку товара из Excel. Приложение не хранит постоянный список товаров, поэтому удалённый товар не будет обрабатываться при следующей загрузке.

## 8. Как работает автоматический подсчёт проблематик

Логика находится в `services/problem_counter.py`:

1. На вход поступает список фактически найденных негативных отзывов.
2. Каждый отзыв классифицируется в `services/review_classifier.py`.
3. Один отзыв может попасть в несколько проблематик.
4. Для каждой проблематики счётчик увеличивается на 1.
5. В отчёт берётся только поле `ProblemGroup.count`.

Количество отзывов нигде не задаётся вручную.

## 9. Как изменить словарь проблем

Откройте `services/review_classifier.py` и измените словарь `PROBLEM_PATTERNS`. Ключ — название проблематики в отчёте, значение — список регулярных выражений.

Пример:

```python
"осыпается": [r"осып", r"крош"]
```

## 10. Mock-режим

Переключатель **Тестовый режим — данные искусственные** нужен для проверки интерфейса и экспорта без обращений к маркетплейсам. В обычном режиме искусственные данные не используются.

## 11. Если WB или Ozon не отдают данные

Маркетплейсы могут менять публичные HTML/API, ограничивать частоту запросов и требовать авторизацию. В этом случае:

- проверьте `.env` и права API-ключей;
- очистите кэш в интерфейсе;
- посмотрите `logs/app.log`;
- замените реализацию конкретного парсера в `parsers/wb_parser.py` или `parsers/ozon_parser.py` без изменения интерфейса `MarketplaceParser`.

WB: предпочтительно использовать официальный Seller API для отзывов. Ozon: для отзывов в обычном режиме нужны `OZON_CLIENT_ID` и `OZON_API_KEY`; публичный HTML Ozon нестабилен.

## 12. Архитектура

```text
app.py                         Streamlit UI и orchestration
models.py                      Pydantic-модели
parsers/base.py                общий интерфейс MarketplaceParser
parsers/wb_parser.py           WB рейтинг и отзывы
parsers/ozon_parser.py         Ozon рейтинг и отзывы
services/excel_reader.py       чтение и нормализация Excel
services/review_classifier.py  негативность и проблематики
services/problem_counter.py    автоматический подсчёт проблем
services/report_generator.py   текстовый отчёт и склонения
services/export_service.py     TXT/DOCX/XLSX
services/cache_service.py      JSON-кэш
assets/style.css               бежево-коричневый дизайн
logs/app.log                   журнал ошибок
outputs/                       отчёты и кэш
```
